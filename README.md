# Casa da Floresta — Demo V2

Guia digital demonstrativo da Casa da Floresta, em Ubatuba (SP).

Esta versão usa as fotos reais fornecidas para a demo e somente informações públicas do anúncio do Airbnb para os dados específicos da hospedagem. Informações privadas como senha do Wi-Fi, contato direto, endereço exato e códigos de acesso não foram inventadas nem exibidas.

## Principais ajustes da V2

- fotos reais em hero, galeria, interior, hidromassagem, localização e encerramento;
- horários públicos de check-in e check-out;
- self check-in, estacionamento, Wi-Fi, cozinha e hidromassagem conforme anúncio;
- localização apenas aproximada, com referência à Praia Dura;
- link para o anúncio oficial no Airbnb;
- remoção de textos de protótipo e placeholders visíveis;
- `noindex` / `nofollow` e bloqueio por `robots.txt`;
- estrutura preservada para futuramente receber os dados privados do anfitrião.

Anúncio de referência: https://www.airbnb.com.br/rooms/1689110478975401158
